Attack surface: Supervisor receives user input as its instruction — no separation between data and commands.
Agent I/O: Each agent inputs the last agent's output + full conversation as context. SetVariable nodes transform Table → String for conditional logic.

Slide 10 — Close 0:45

Three Things to Remember

1
Narrow your agents' scope
The tighter the task, the stronger the model's native defense.
2
Separate instruction channels from data channels
If user input goes straight to the orchestrator unfiltered, you have a gap.
3
Test before you trust
Platform guardrails missed 100% of our attacks.
Model behavior is the real safety layer — verify it empirically.
